When reviewing code, follow these principles:
1. Check for security vulnerabilities first
2. Verify error handling is comprehensive
3. Ensure code follows the project's style guide
4. Look for performance bottlenecks
5. Confirm proper input validation
6. Check for proper logging and monitoring
7. Verify tests cover edge cases
8. Review for readability and maintainability

Always provide constructive feedback with specific examples.
